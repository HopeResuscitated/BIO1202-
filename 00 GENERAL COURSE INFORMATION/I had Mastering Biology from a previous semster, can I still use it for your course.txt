I had Mastering Biology from a previous semster, can I still use it for your course?

Yes and no, it depends.  If you purchased Mastering from a previous semester and it
was for OUR TEXTBOOK (each access code is linked to a specific textbook, it is not a
UNIVERSAL access code), then it may still be good.

Once a Mastering Biology access code is activated, it is good for 18 consecutive months.
So, if you are using access that had been activated from a previous semester, be sure
that it will carry you through the entire current semester.
